# Project rules

## Higgsfield: NEVER spend credits (hard rule from the owner)

- **Never spend a single Higgsfield credit. No exceptions.**
- When generating a video on Higgsfield, use exactly these settings:
  - Model: **Seedance 2.5** (`seedance_2_5`)
  - Resolution: **720p**
  - Duration: **20 seconds**
  - Unlimited: **ON** (`use_unlim: true`) on every request
- One video per request. Tell the owner before each generation.
- If the unlimited request is refused or shows as unavailable, **stop and tell the owner**. Do not retry with credits, change model or settings, or leave `use_unlim` unset.
- Never use other paid Higgsfield tools (images, audio, upscales, batches, presets) unless they are covered by unlimited under the same rule.

## Originality rule (from the owner)

- Every script and shot list must be completely original. **No reused shot, camera move, location, angle, prop or framing** from earlier videos.
- Before writing a shot list, read `shotlist.md` (the log of everything used) and avoid all of it. Append each new video's shots to that log.
- Each scene needs its own setting, its own lighting and its own camera move (orbit, crane, low tracking, overhead top-down, POV, rack focus, dolly zoom, whip pan, tilt, roll…).
- Never repeat a move within one video. Never default to a push-in or a locked-off medium shot.
- If an idea feels familiar, throw it out and find a stranger, more specific one.
- Always keep the reverse-engineered editing formula in `style.md`.

## Default video format for new scripts

- When the owner sends a script, build it in the **Roddy Games format** documented in `roddy_style.md`: logo emblem sting with a glint at 0s, 1–3-word captions with a yellow/magenta key word, the Vice City gradient card stage, side-by-side proof, icon pops, animated numbers, article highlighter sweeps and the subscribe-click ending.
- Render at 1080×1920 at −18 LUFS, and keep the file under about 28 MB so it sends first time.
