# Project rules

## Higgsfield: NEVER spend credits (hard rule from the owner)

- **Never spend a single Higgsfield credit. No exceptions.**
- When generating a video on Higgsfield, use exactly these settings:
  - Model: **Seedance 2.5** (`seedance_2_5`)
  - Resolution: **720p**
  - Duration: **20 seconds**
  - Unlimited: **ON** (`use_unlim: true`) on every request
- One video per request. Tell the owner before each generation.
- If the unlimited request is refused or shows as unavailable, **stop and tell the owner**. Do not retry with credits, change model or settings, or leave `use_unlim` unset.
- Never use other paid Higgsfield tools (images, audio, upscales, batches, presets) unless they are covered by unlimited under the same rule.
